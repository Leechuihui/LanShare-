# 局域网高速文件传输服务器 🚀

一个基于 Python aiohttp 的局域网文件共享工具，支持高速上传/下载、实时在线设备监测和传输动态显示。

## ✨ 特性

- **🔥 高速传输**: 4MB 大块读写，充分利用千兆局域网带宽
- **📊 实时状态**: WebSocket 实时更新在线设备和传输记录
- **⚡ 并行上传**: 支持最多 4 路并发上传
- **🎯 零配置**: 自动检测本机 IP，开箱即用
- **💾 断点续传友好**: 原始二进制直传，无 multipart 开销
- **📱 响应式设计**: 适配桌面和移动设备

## 📋 系统要求

- Python 3.8+
- 局域网环境（推荐千兆网络）
- 现代浏览器（Chrome、Edge、Firefox、Safari）

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

或者自动安装（首次运行会自动安装 aiohttp）：

```bash
python server.py
```

### 2. 启动服务器

```bash
python server.py
```

服务器将自动启动在 `http://127.0.0.1:8082/`，并在局域网内广播 IP 地址。

### 3. 访问界面

- **本机访问**: http://127.0.0.1:8082/
- **局域网访问**: http://{你的局域网 IP}:8082/

## 📖 使用说明

### 设备命名

1. 在顶部输入框填写设备名称（例如："家里的 Mac"）
2. 点击"保存名称"按钮
3. 名称将保存在本地 localStorage，下次自动填充

### 上传文件

**方式一：拖拽上传**
- 直接将文件或文件夹拖到虚线区域
- 支持多文件同时选择

**方式二：选择文件**
- 点击"选择文件"按钮选择单个/多个文件
- 点击"选择文件夹"按钮上传整个文件夹

**开始上传**
- 选中文件后，点击"开始高速上传"
- 实时显示进度、速度和传输状态

### 下载文件

1. 在"可下载文件"列表中找到目标文件
2. 点击"高速下载"按钮
3. 实时显示下载进度和速度

### 清除缓存

点击"清除缓存"按钮重置设备标识和本地存储的名称。

## 🛠️ 技术实现

### 后端架构

- **框架**: Python aiohttp
- **并发模型**: asyncio + ThreadPoolExecutor
- **块大小**: 4MB（适配大文件传输）
- **磁盘缓冲**: 8MB
- **线程池**: 8 个工作线程

### 前端特性

- **WebSocket**: 实时状态同步（15 秒心跳）
- **并行上传**: 最多 4 路并发
- **进度显示**: XHR 上传/下载实时进度
- **本地存储**: localStorage 保存设备信息

### API 接口

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | Web 界面 |
| `/ws` | GET | WebSocket 连接 |
| `/api/state` | GET | 获取完整状态（在线设备、活动记录、文件列表） |
| `/api/files` | GET | 获取文件列表 |
| `/upload-raw/{path}` | PUT | 高速原始流上传 |
| `/upload` | POST | 兼容 multipart 上传 |
| `/files/{path}` | GET | 文件下载 |

## 📊 性能优化

1. **大块读写**: 4MB 传输块，减少系统调用
2. **线程池写盘**: 异步读 + 同步写盘，避免阻塞事件循环
3. **并行上传**: 客户端 4 路并发，服务器端支持多请求处理
4. **原始二进制**: PUT 直传，避免 multipart 解析开销

## 🔧 配置选项

在 `server.py` 中可调整以下参数：

```python
CHUNK = 4 * 1024 * 1024  # 传输块大小（默认 4MB）
DISK_BUF = 8 * 1024 * 1024  # 磁盘缓冲（默认 8MB）
IO_POOL = ThreadPoolExecutor(max_workers=8)  # 线程池大小
CONCURRENCY = 4  # 客户端并行上传路数
```

## 🐛 故障排查

**问题：设备离线频繁**
- 检查网络连接稳定性
- 确保浏览器未休眠（标签页保持激活）

**问题：上传速度慢**
- 确认使用千兆网络
- 关闭其他占用带宽的应用
- 尝试增加并发数（修改 `CONCURRENCY`）

**问题：文件列表不更新**
- 点击"刷新"按钮手动刷新
- 检查 WebSocket 连接状态（顶部显示绿色圆点为正常）
